# 🧭 Emotion Finder

A lightweight, self-contained tool that helps you identify what you're feeling through six simple questions.

Accurately naming an emotion is a foundational skill in therapies like Cognitive Behavioral Therapy (CBT). Emotion Finder uses a dimensional scoring model to triangulate your emotional state from nearly 100 emotions, helping you move from "I feel bad" to something more precise — which is the first step toward working with it.

## How it works

Answer six questions about your current feeling — how it feels, your energy level, how much it involves other people, your sense of control, how clearly you understand it, and whether you want to move toward or away from it. The app calculates the closest matches from its emotion library and presents the top three.

## Features

- No installation, no internet required — just open the HTML file in any browser
- 124 emotions scored across six psychological dimensions
- Built-in editor (click the ⊕ in the bottom right corner) to add, edit, or remove emotions
- Theme customization
- Export as a clean quiz-only version or a full editable version

## Usage

Download `index.html` and open it in any modern browser. No setup required.
